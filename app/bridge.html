The Bridge

A city's only bridge is wired with 256 sensors, and one office decides every morning whether it is safe to cross. No person can read 256 raw readings, so computers summarize them in stages: 256 readings become 64 reports, then 16 findings, then 8 claims — one per section of the bridge — then the one sentence on the desk: THE BRIDGE IS SAFE. 21,000 people cross on that sentence. You are watching the summarizing system built twice on the same budget, under two different rules for which supporting links get kept. The same 10 computers fail in both towers, and we measure one thing: for each claim still on the desk, can an engineer still trace it down to a real sensor reading? Blue: a claim an engineer can still trace. Orange: a claim still being used, with nothing checkable underneath it.

The lessonWe damaged both towers of summaries the same way. The tower that had kept a short note about every sensor connection it ever discarded used those notes to rebuild every broken path from its conclusions down to real readings. The tower that kept no notes rebuilt nothing — 14,420 people were left crossing the bridge on conclusions that can no longer be checked against any sensor. When a system throws information away, make it write down what it threw.
